Cara Penggunaan Website

  1. Mengakses Website
    User memasukkan URL website pada kolom URL browser dan akan diarahkan ke halaman Dashboard.
  2. Unggah Gambar
    Pada halaman Egg Classification, unggah gambar yang diinginkan lalu klik Upload.
  3. Proses Analisis
    Sistem akan menganalisis data menggunakan algoritma klasifikasi untuk menentukan mutu telur.
  4. Melihat Hasil Klasifikasi
    Hasil analisis akan ditampilkan dalam bentuk kategori mutu telur seperti Mutu I, II, III.
  5. History Data
    User dapat melihat rekap data yang telah diproses dalam bentuk tabel dengan tanggal dan tombol untuk melihat detail proses klasifikasi.

Parameter Mutu Telur

1. Warna Cangkang
  • Coklat Tua: Kualitas baik.
  • Coklat: Kualitas sedang.
  • Coklat Pucat: Kualitas buruk.
2. Kondisi Cangkang
  • Baik: Tidak ada retak atau cacat.
  • Retak Halus: Ada sedikit garis retak tetapi belum pecah.
  • Rusak: Cangkang pecah atau berlubang.
3. Kebersihan Cangkang
  • Bersih: Tidak ada noda atau kotoran.
  • Sedikit Kotor: Ada noda kecil tetapi masih aman.
  • Sangat Kotor: Banyak noda yang dapat mengurangi kualitas telur.
